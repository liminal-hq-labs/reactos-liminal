# Stock shortcuts and the programs they run, so a trim that removes a program removes its shortcuts too.
#
# Each line is `PATH => TARGET`: the shortcut the stock ReactOS install writes into each user's profile, and the program it runs. PATH
# under a profile folder (`Documents and Settings/Default User`, `Administrator`, `NetworkService` and `All Users`) and TARGET under the
# FAT32 root. A trim that removes a TARGET removes its shortcuts from every profile, and a Start menu folder left empty, so a menu
# never lists a program that is not on the disk. `rl audit` on the full image lists exactly these links; the stock list is complete
# when it reports no shortcut missing here.
