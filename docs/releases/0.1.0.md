**Afterglow for ReactOS 0.1.0** is the first release of ReactOS Liminal: the official ReactOS 0.4.16 install CD with the Afterglow desktop theme's pointers, a trimmed install and settings built into a disk image from a recipe, and the licence texts, source offer and list of changes added to the disc.

**Unofficial.** This is an unofficial remaster by Liminal HQ Labs. It is not made, endorsed or supported by the ReactOS Project. ReactOS is a trademark of the ReactOS Project. Report problems here, not to ReactOS.

## Downloads

- **`afterglow-for-reactos-v0.1.0-unofficial-remaster.iso`** is the install CD. It is the official ReactOS 0.4.16 disc with a second session added that holds `NOTICE.txt`, `CHANGES.txt` and the `LICENSES` folder. Nothing that was on the disc has moved, and it boots the same way.
- **`SHA256SUMS`** covers every file. Check your download against it with `sha256sum -c SHA256SUMS`.
- **`build-manifest.json`** records the SHA-256 of every output, the pinned inputs (the official ISO and the Afterglow commit), the trim profile, the patchers and how long each stage took. **`afterglow.lock.json`** is the lock file the build was checked against.
- **`licences.md`** says what each part of the system is licensed under and where the texts are.
- **The corresponding source:** `reactos-0.4.16-release-source.tar.gz`, `reactos-liminal-v0.1.0-source.tar.gz` and `SOURCE.txt`, which also carries the written offer for the source.

## What is in it

- **A build from code.** Every input is pinned by SHA-256 and the build records every output's hash, so the disc and the disk can be rebuilt and compared. `rl verify` fails when a pin or the lock file has drifted.
- **What the disk builds are.** `rl image` turns an unattended install into a disk with the Afterglow pointers as the system pointers (a patched copy of `user32.dll`, refused unless the stock file is exactly the one it was written for), a trimmed set of programs, the Afterglow visual style, and display, quiet and watermark settings.
- **Licences and notices.** `LICENSES` holds the GPL-2.0, LGPL-2.1, Apache-2.0 and MIT texts. `NOTICE.txt` says what the system is, carries the source offer and lists the components and their licences. `CHANGES.txt` lists every patched file with its SHA-256 before and after, every removed path and the settings applied.
- **Browser disk parts.** The same image is split into zstd parts for the v86 emulator; the parts are a build output and are not attached to the release.

## Known limits

- The disc is the official install disc with the notices added. Setup, the logon screens and the boot menu are not themed yet, and the extra cabinet that installs the Afterglow desktop during Setup is not in this release; the themed disk is a build output of the recipe.
- The ISO is not yet reproducible byte for byte: it carries the build's timestamps. The contents are covered by `SHA256SUMS` and the manifest.
- The licence table is taken from ReactOS's own documentation and is confirmed file by file before each ISO release; the WineVDM source is named, not attached.
- There is no network in the guest and no Microsoft file anywhere in the build.
