**Afterglow for ReactOS 0.1.0** is the first release of ReactOS Liminal: the disk parts of an Afterglow-dressed ReactOS 0.4.16, built from the official install CD by a recipe, with the build manifest, the licences and the source pointer.

**Unofficial.** This is an unofficial remaster by Liminal HQ Labs. It is not made, endorsed or supported by the ReactOS Project. ReactOS is a trademark of the ReactOS Project. Report problems here, not to ReactOS.

## Downloads

- **`v86-disk-parts-v0.1.0.tar`** holds the zstd parts of the built disk image and their `manifest.json`, for the v86 emulator in a browser.
- **`SHA256SUMS`** covers every file. Check your download against it with `sha256sum -c SHA256SUMS`.
- **`build-manifest.json`** records the SHA-256 of every output, the pinned inputs (the official ISO and the Afterglow commit), the trim profile, the patchers and how long each stage took. **`afterglow.lock.json`** is the lock file the build was checked against.
- **`licences.md`** says what each part of the system is licensed under and where the texts are.
- **The source:** `reactos-liminal-v0.1.0-source.tar.gz` and `SOURCE.txt`, which names the ReactOS source by tag and commit and carries the written offer for the source.

## What is in it

- **A build from code.** Every input is pinned by SHA-256 and the build records every output's hash, so the disk can be rebuilt and compared. `rl verify` fails when a pin or the lock file has drifted.
- **The disk.** An unattended install with the Afterglow pointers as the system pointers (a patched copy of `user32.dll`, refused unless the stock file is exactly the one it was written for), a trimmed set of programs, the Afterglow visual style, and display, quiet and watermark settings. `LICENSES`, `NOTICE.txt` and `CHANGES.txt` on the disk carry the licence texts, the source offer and every patched file with its SHA-256 before and after.

## Known limits

- **No install ISO yet.** A remastered ISO is planned for a later release. Today it would be the stock ReactOS disc with the licence texts added, which is not worth shipping; it waits for Setup theming. Build it yourself with `rl iso` if you want it.
- The licence table is taken from ReactOS's own documentation and is confirmed file by file before each release; the WineVDM source is named, not attached.
- There is no network in the guest and no Microsoft file anywhere in the build.
